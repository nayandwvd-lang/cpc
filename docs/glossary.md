# Glossary

Every technical word this guide uses, explained in ordinary English — no prior law assumed.

There are two ways to use this page. If a word ambushed you somewhere in the guide, type it into the filter box below and read the one entry. If you have never studied procedure at all, ignore the alphabet entirely and read the eight groups in order: they follow the life of a case, so each group teaches you the vocabulary you need before the next group can make sense.

::: tip Two rules that make the whole vocabulary easier
**One.** Procedure words are almost always doing one of four jobs: naming a *person* (plaintiff, decree-holder, garnishee), naming a *piece of paper* (plaint, written statement, decree), naming a *stage* (first hearing, framing of issues, execution), or naming a *test the court applies* (prima facie, sufficient cause, substantial question of law). When you meet a new word, ask which of the four it is. That alone removes most of the confusion.

**Two.** A word can mean something narrower in the Code than it does in ordinary speech. "Decree" is not any decision. "Order" is not any instruction. "Suit" is not any dispute. Where that gap exists, the entry below says so explicitly — those are the entries worth reading twice.
:::
